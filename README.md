## ✨ Features

- 🎯 **25 Attack Categories** — Recon to Exploitation
- ✅ **300+ Actionable Steps** — Real commands, not theory
- 🔍 **Live Search** — Search across all techniques instantly
- 🏷️ **Phase Filters** — RECON, DNS, WEB, AUTH, API, INJECT, LOGIC
- 📊 **Progress Tracking** — Per category and overall
- 📱 **Fully Responsive** — Mobile, tablet, desktop
- 🌑 **Hacker Dark Theme** — Easy on eyes during long hunts

cd bug-bounty-methodology
